About This Dashboard

The Australia Weather Monitoring Dashboard collects weather information for seven Australian cities using the Open-Meteo weather API. Flask manages the web application, Firebase Realtime Database stores weather records, and Pandas and Seaborn support data processing and visualization.

Users can filter weather records by city, review summary statistics, compare weather conditions through charts, and refresh the stored weather information.
